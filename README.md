# cuddly-fiesta

Weekly startup sourcing scraping tool prototype.

## What it does

- Lets users manually choose which startup discovery websites are included in a weekly sourcing run.
- Offers AI-style recommendations for similar websites to expand the sourcing list.
- Simulates scraping startups from curated sources.
- Compares found startups against an in-app HubSpot CRM dataset.
- Produces a clean net-new startup list with short summaries of what each startup is working on.

## Run locally

```bash
npm start
```

Then open `http://localhost:3000`.

## Checks

```bash
npm run check
```
